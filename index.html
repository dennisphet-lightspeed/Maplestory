Mock Client Site — GA4 Cross-Domain Test Harness

This page simulates a golf club's own website that has its own GA4 property with cross-domain linking configured to point at the Chronogolf widget domain. Use it to test that the original client/session ID and campaign attribution survive the hop into the widget.

Served over HTTPS (GitHub Pages)? The iframe test (Test B) requires the widget URL to also be HTTPS, otherwise the browser blocks it as mixed content. Point the widget URL at a production/staging HTTPS host for Test B. Test A (direct link) works regardless.

Config

The client GA4 tag loads only after you click Apply, so you can set the ID first.

Test A — Direct link (exercises the _gl linker path)

GA4's linker auto-appends ?_gl=... to this link because the target domain is in the linker domains list. The widget's accept_incoming: true then restores the original client ID. Open in a new tab and inspect the URL — it should contain _gl.
